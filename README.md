# Pal Super Nintendo endlables
An open source customisable endlable for Super Nintendo game cartridges

## Usage

### Download printing documents

if all you're looking for is a printable PDF file containing all current lables.
Go to the [Download links](#download-links) section and select the format you enjoy the most,
Screenshot examples will be given above the link for reference.  
These Links will include a Print-ready PDF file with all the games currently supported in the chosen customisation,
aswell as a folder containing all individual lables as PNGs. These can be used to print out lables for just the games you want or have.

For a list of all current included games see the [Supported Games](#supported-games) section.
